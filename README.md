<h2 align="center">🛠️ Production Troubleshooting</h2>

<div align="center">

Problem

Investigation

Pod Pending

kubectl describe pod → scheduler events → taints / selectors / resources / PVC

CrashLoopBackOff

logs → previous logs → environment → probes → dependencies

ImagePullBackOff

image name → tag → registry authentication → network

Service unavailable

Pod → endpoints → Service → port → selector

Ingress issue

DNS → controller → Ingress → Service → endpoints

PVC Pending

StorageClass → provisioner → node affinity → capacity

Node NotReady

kubelet → runtime → CNI → resources → networking

Deployment failure

rollout status → ReplicaSet → events → logs

API connection issue

DNS → URL → CORS → Service → backend health

Monitoring alert issue

rule → Prometheus → Alertmanager route → receiver
